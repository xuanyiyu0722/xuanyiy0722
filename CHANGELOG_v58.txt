v58 — 从 v55 原版重新制作的插画动效

基础文件：alicia_portfolio_complete_v55.zip

首页开场
- 使用原线稿蛋形象，先在屏幕中央放大出现，再缩回左上角标志位置。
- There’s / more / beneath / the / EGGshell 逐行渐显，蛋盒随后出现。
- 开场结束后保持 v55 的正常页面布局。
- 用户开始滚动、点击或按 Escape 等导航键时可立即跳过开场。
- 手机端缩回顶部移动导航的蛋标志。

侧栏导航
- Home / Project Gallery / About 的 emoji 换成手绘 SVG 蛋与小鸡。
- 蛋壳带小花装饰；悬停或键盘聚焦时画出裂缝并轻晃。
- 点击后蛋壳弹开、小鸡跃出，再进入目标页面。
- 当前页面以已孵化的小鸡表示，小鸡悬停时挥动翅膀。
- 保留链接的键盘、修饰键及新标签打开方式。

项目大数字
- 逐页按实际字号核查四个项目，共覆盖初始页面中的 41 处突出数字。
  NABORFOOD：14 处；FridgeKey：12 处；EverPaw：12 处；MUSUBI：3 处。
- 包含市场规模、增长率、消费比例、调查样本、评分、研究数据、成本、
  价格区间及原型中的运动数据，不只最初举例的三个数值。
- 进入视口时从零递增，逐渐减速，最终准确停在 v55 的原始数值。
- 保留货币符号、单位、百分号、小数精度、千位逗号及区间。
- 动画过程中保留最终数字宽度，避免周围排版跳动。
- NABORFOOD 原型重新渲染时，新出现的运动大数字也会自动应用动画。
- 屏幕阅读器与打印始终使用原始最终值。

兼容
- 系统启用“减少动态效果”时，显示最终页面与原始数据，导航直接跳转。
- 新增动效不依赖外部 JavaScript 库。
- 原有项目内容、样式、脚本、图片、视频和蛋盒点击预览保留。
