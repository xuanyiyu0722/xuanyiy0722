# Alicia Xuanyi Yu — Portfolio

A static portfolio built with the existing HTML, CSS and JavaScript website.

- Entry: `index.html`
- Pages: Home, Project Gallery, About, and four case studies
- Live website: https://alicia-portfolio-three.vercel.app/
- Deployment: GitHub `main` → Vercel project `alicia-portfolio` (connected)
- No runtime or build dependencies; Node.js 24 is used for deployment checks.

See [DEPLOYMENT.md](DEPLOYMENT.md) for setup and the ongoing publishing workflow.

```sh
npm run check
npm test
npm run build
npm run setup:git
```

Edit source files in this repository. The `dist/` directory is generated and ignored by Git.
